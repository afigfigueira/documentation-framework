# 4. Classification Element

A Classification Element is a conceptual semantic role or dimension through which a governed documentary distinction is expressed. Family, Type and Class are the principal documentary roles considered here, with current meanings in §§6–8. They are not interchangeable labels, three automatically created Metadata Elements or architectural components.
