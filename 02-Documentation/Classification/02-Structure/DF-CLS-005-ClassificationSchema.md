# 1. Introduction

This document defines a working formal structural contract for applicable documentary Classification claims. It uses current reviewed Architecture DF-CLS-001, Concepts DF-CLS-002, reconstructed Model DF-CLS-003 and Elements DF-CLS-004, all V2.0 R1, with their actual local authority and acceptance limits. The three original documentary role subjects remain:

- Family;
- Type;
- Class.

Their current meanings are actual component/admitted-area membership, exactly one uniform primary responsibility and an optional additional explicitly defined non-conflicting distinction. This edition states justified structural obligations and exposes missing general multiplicity/owner authority; it does not manufacture a complete physical record, vocabulary or implementation. Technology/serialization neutrality does not waive actual representation interfaces or evidence.
